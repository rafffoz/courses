Assignment and arithmetic operators

Operator Example Same as Arithmetic operator Description
= x = y x = y Equal y is stored in x
+= x += y x = x + y Addition x + y result is stored in x
-= x -= y x = x - y Substraction x - y result is stored in x
*= x *= y x = x * y Multiplication x * y result is stored in x
/= x /= y x = x / y Division x / y result is stored in x
%= x %= y x = x % y Modulus x % y result is stored in x
**= x **= y x = x ** y Exponential x ** y result is stored in x

Comparison operator

Operator Name Example
== Equal in value only: Equivalent x == y
=== Equal in value and data type: exactly equal x === y
!= Not equal x != y
> greater than x > y
>= greater than or equal to x >= y
< lesser than x < y
<= lesser than or equal to x <= y
